Are there more earthquakes than usual this year?

Loading the catalog…

Many people ask whether there have been an unusual number of large earthquakes recently. They may have been told that the number of large earthquakes is increasing. This page shows the data, updated live from the USGS. The answers here are calculated automatically from that data.

Magnitude M6+ counts every earthquake of magnitude 6.0 and up. M7+ counts only 7.0 and up.

We don’t show any smaller earthquakes, because the catalog becomes less reliable for smaller events as you step back in time.
Period This year counts from January 1, and compares against the same stretch of every earlier year back to 1976.

Last 365 days shows a full twelve months, ending today, with matching time windows from previous years.
Measure Count treats every earthquake as a data point of equal weight. Moment weights each earthquake by its strength. Each step up in the magnitude scale is about 32 times more moment, so one M8 is equivalent to one thousand M6s. A single great earthquake can dominate a whole year.
Catalog A big earthquake is followed by hundreds of smaller aftershocks — so a year with one great earthquake might appear to be much busier than usual. Select Mainshocks only to remove these aftershocks. This is called declustering.
